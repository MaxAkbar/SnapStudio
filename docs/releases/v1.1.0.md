# SnapStudio 1.1.0

SnapStudio 1.1 adds editable layer folders and object groups, stamps, precise
selections, snapping, and perspective drawing tools, with a more focused Inspector.

## Download and run

Requires **Windows 11 x64**. Download **`SnapStudio-1.1.0-win-x64-portable.zip`**,
extract the entire archive, and run **`SnapStudio.App.exe`**. Keep all DLLs,
Assets, and Docs folders together. The ZIP includes .NET and the Windows App SDK
runtime; Visual Studio and the .NET SDK are not required. Help and the SVG
designer require the Microsoft Edge WebView2 Runtime.

## What's new since 1.0.0

- **Layer folders and object groups.** Group layers into folders, group object
  rows within a layer, merge selections while keeping objects editable, and cut
  or move objects between layers. Folders and object groups cannot be nested.
  Membership, masks, visibility, and undo/redo are preserved.
- **Precise selections.** Rectangular and elliptical marquees, freehand and
  polygonal lassos, and a magic wand support copying, filling, moving the
  selection outline, adding layer masks, and cropping individual layers.
- **Stamps and reusable SVG patterns.** Place built-in stamps, import SVG artwork,
  or search the optional online Iconify catalog. Design custom SVG line motifs
  that repeat along shapes and curves, with adjustable scale and spacing.
- **Snapping in both editors.** Align edges and centers, use adjustable canvas
  and SVG grids, and bypass snapping temporarily with Alt.
- **One- through five-point perspective.** Edit vanishing points and the horizon,
  adjust each guide family's color, opacity, density, and visibility, and draw
  perspective rectangles or curved perspective lines. Choose per-object snapping
  targets and keep perspective objects aligned when moved.
- **SVG editing improvements.** Duplicate, delete, arrange, and transform objects
  and groups, with undo/redo and snapping.
- **Workspace improvements.** Inspector tabs for Properties, Image details,
  Capture options, and Guides; a Theme switch beside Settings; object hover,
  move, and resize while keeping a drawing tool active; and automatic workspace
  minimization during capture.
- **Fixes.** Correct light-theme tool shortcut colors, restore layer context-menu
  deletion, fix startup with the new layer tree, and retain tree rows during
  selection, movement, and collapse to prevent flicker and disappearing rows.
- Updated Windows App SDK, Windows SDK BuildTools, CSharpDB, System.Drawing,
  and MSTest dependencies.

## Compatibility and package details

- This is a stable release. Existing documents migrate to schema 12 when opened.
  Keep backups before editing with 1.1; documents saved by 1.1 cannot be opened
  by versions that only support older document schemas.
- Captures and settings remain in your local Windows profile. The portable
  package does not store them beside the executable.
- The executable is unsigned, so Windows may show an unrecognized-app warning.
- OCR, scrolling capture, and screen recording remain experimental and disabled
  by default. Broader hardware and packaged-build QA for these lanes is pending.
- Only Windows x64 is packaged here. Store certification and signed distribution
  remain separate work.
- `SnapStudio_1.1.0.0_x64.msix` is an unsigned, framework-dependent evaluation
  package. Installation requires trusted signing and matching .NET 10 and
  Windows App SDK runtimes. Use the portable ZIP for normal use.
- `SHA256SUMS.txt` verifies both packages and the validation reports.
  `release-validation.txt` records checks and their limits;
  `release-readiness.md` records the default feature and documentation gates.
