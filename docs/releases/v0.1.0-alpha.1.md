# SnapStudio 0.1.0-alpha.1

The first GitHub preview packages the current Windows capture and annotation editor for testing.

## Included

- Region, window/picker, display, and full-screen capture entry points.
- A local capture workspace with thumbnails, search, rename, duplicate, and export workflows.
- Editable shapes, arrows, text, highlights, and blur, with undo and redo.
- Annotation layers with visibility controls and undoable deletion. Deleting the final layer is blocked; deleting a populated layer asks for confirmation.
- Resizable, collapsible Layers/Recent Captures and annotation tools panes, with retained widths and clear zoom controls.
- Crop, resize, clipboard copy, PNG/JPEG/PDF export, and local settings.
- File-system or CSharpDB document storage, with serialized document saves and local diagnostics/recovery support.

## Download and run

Requires Windows 11 x64. Download `SnapStudio-0.1.0-alpha.1-win-x64-portable.zip`, extract the entire archive, and run `SnapStudio.App.exe`. Keep its DLLs and other files together. The ZIP includes .NET and the Windows App SDK runtime; it does not require a .NET SDK installation.

The executable is unsigned. Windows may show an unrecognized-app warning. Captures and settings are stored in the local Windows profile, rather than next to the executable.

`SnapStudio_0.1.0.0_x64.msix` is an unsigned, framework-dependent development package for packaging evaluation. It requires signing with a trusted certificate before local installation, plus the matching .NET 10 and Windows App SDK runtimes. See [packaging](https://github.com/MaxAkbar/SnapStudio/blob/v0.1.0-alpha.1/docs/packaging.md). Use the portable ZIP for the preview.

`SHA256SUMS.txt` contains checksums for the downloadable ZIP and MSIX.

## Preview limits

- OCR, scrolling capture, and screen recording remain experimental and disabled by default. Their full manual QA is pending.
- Microsoft Store identity, hosted listing URLs, package certification, and signed distribution remain pending.
- This release targets x64. Other architectures have not been packaged or validated for this preview.
- The separate HTML UI prototype is exploratory work and is not included in the release.

## Validation

- Formatting verification passed.
- The Release x64 solution build passed with zero warnings or errors.
- All 263 tests passed, including layer deletion, undo/redo ordering, and protection of the final layer.
- The MSIX packaging smoke verified the version, x64 payload, manifest, privacy notes, and unsigned status.
- The Release UI smoke passed, including pane collapse/restore and settings controls.

The release includes a readiness report and validation record with the checks performed for this preview. Readiness checks cover default feature flags and documented packaging/privacy gates; they do not certify the optional feature lanes or Microsoft Store readiness.
