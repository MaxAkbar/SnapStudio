# SnapStudio 1.0.0

SnapStudio 1.0 is the first stable GitHub release: capture a screenshot, explain
it with editable notes, organize it locally, and copy or export the result.

## Download and run

Requires **Windows 11 x64**. Download
**`SnapStudio-1.0.0-win-x64-portable.zip`**, extract the entire archive, and run
**`SnapStudio.App.exe`**. Keep its DLLs, Assets, and Docs folders together.

The ZIP includes .NET and the Windows App SDK runtime. Visual Studio and the
.NET SDK are not required. The built-in HTML Help and SVG designer require the
Microsoft Edge WebView2 Runtime.

The executable is unsigned, so Windows may show an unrecognized-app warning.
Captures and settings are stored under the local Windows profile, rather than
beside the executable. Existing local workspaces and settings are retained.

## Included

- Region, window/picker, display, and full-desktop still capture. Captured mouse
  pointers are separate editable image objects.
- Editable arrows, shapes, text, highlights, pen, blur, and fill, with Move and
  Marquee tools, undo/redo, crop, resize, and clipboard image layers.
- Annotation layers, object ordering, visibility, and reusable tool designs.
- A built-in SVG designer with reusable artwork, object editing, paths,
  grouping, transforms, and SVG import/export.
- A searchable library with tags, folders, mapped-folder imports, thumbnails,
  pagination, and capture management.
- PNG, JPEG, and PDF export, plus selection-aware clipboard copy.
- Resizable and collapsible panes, Focus mode, and dark, light, or system theme.
- Searchable offline HTML Help from the toolbar or F1.
- Local file-system or CSharpDB document storage, settings transfer, diagnostics,
  and recovery logging. No account, cloud sync, or automatic upload.

## Package details and limits

- This is a stable release, not an alpha or GitHub prerelease.
- OCR, scrolling capture, and screen recording remain experimental and disabled
  by default. Broader hardware and packaged-build QA for these lanes is pending.
- The release targets x64. ARM64 and x86 are not packaged or validated here.
- Microsoft Store certification and signed distribution remain separate work.
- `SnapStudio_1.0.0.0_x64.msix` is an unsigned, framework-dependent package for
  packaging evaluation. It requires signing with a trusted certificate and the
  matching .NET 10 and Windows App SDK runtimes before installation. Use the
  portable ZIP for normal use.
- `SHA256SUMS.txt` contains checksums for the ZIP, MSIX, and validation reports.
  `release-validation.txt` records the release checks; `release-readiness.md`
  records the default feature gates and documentation/privacy checks.

For source builds and packaging commands, see the
[packaging guide](https://github.com/MaxAkbar/SnapStudio/blob/v1.0.0/docs/packaging.md).
The [privacy disclosure](https://github.com/MaxAkbar/SnapStudio/blob/v1.0.0/docs/privacy.md)
describes local data and diagnostics.
