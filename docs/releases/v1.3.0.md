# SnapStudio 1.3.0

Use copied colors in your annotations, and add optional capture and editing commands to PowerToys Command Palette.

## Download and start

Download [the Windows x64 portable ZIP](https://github.com/MaxAkbar/SnapStudio/releases/download/v1.3.0/SnapStudio-1.3.0-win-x64-portable.zip), extract the **entire archive**, and open **SnapStudio.App.exe**. Requires Windows 11 x64. The ZIP includes .NET and the Windows App SDK runtime; Help and the SVG designer require the Microsoft Edge WebView2 Runtime.

**PowerToys is optional.** SnapStudio's normal capture, editing, clipboard, library, and export workflows work without it. The editor does not install or start PowerToys, check for it at startup, or show reminders when it is missing. The main download does not contain the Command Palette SDK or companion.

## What's new since 1.2.0

- **Use clipboard color:** copy an RGB hex color from any application, select an annotation or drawing tool, open its color picker in Properties, and choose **Use clipboard color**. Supports `#RRGGBB`, `RRGGBB`, `#RGB`, and `RGB`. Invalid clipboard text leaves the color unchanged; object changes use the normal undo workflow.
- **Optional Command Palette companion preview:** adds **SnapStudio: Capture a region**, **SnapStudio: Edit clipboard image**, and **SnapStudio: Open most recent image**. Clipboard images open as new editable documents; most-recent-image commands work across all folders and tags.
- **Local launcher connection:** reuses the running editor, reports busy dialogs and captures, validates command versions and request IDs, and cancels pending work when the launcher disconnects. The companion receives status rather than screenshot pixels or library contents.
- **Capture cancellation:** restores the workspace and treats cancellation during Windows preview teardown as cancellation rather than an unrelated capture error.
- **Updated offline Help:** includes the new commands, clipboard colors, optional setup, privacy details, and troubleshooting. Help stays local and searchable.

## Optional companion installation

The companion is a separately installed, unsigned **preview**, not part of the normal SnapStudio setup.

1. Install PowerToys with Command Palette.
2. Download `SnapStudio.CommandPalette-1.0.0.0-x64-development.zip` from this release and extract the **entire archive** into a permanent folder.
3. With Windows Developer Mode already enabled by you, run `Install.ps1` in PowerShell. The installer does not enable Developer Mode or change PowerToys settings.
4. Open SnapStudio 1.3.0 and finish setup, enable Command Palette in PowerToys, and reload its extensions. Open Command Palette, type **SnapStudio**, and choose a command.

Keep the extracted companion folder in place while it is registered. Run its `Uninstall.ps1` before moving or removing that folder; unregistering the companion does not remove SnapStudio or your captures. Close an older SnapStudio copy before using the new companion. If you move the portable editor, open it once from the new location, or enter the full path to `SnapStudio.App.exe` in the extension's settings.

The companion MSIX is an unsigned evaluation package for signing and packaging work. Double-click installation requires trusted signing; the development ZIP is the explicit preview setup path. Signed and Microsoft Store distribution remain separate work. See the [full setup guide](https://github.com/MaxAkbar/SnapStudio/blob/v1.3.0/docs/powertoys-integration.md).

## Compatibility and validation limits

- The document format remains schema 12. Existing captures and settings stay in the same local profile. ExactFrame 2.2.0+ integration continues to use its existing version 1 region-capture protocol.
- The main portable download is unsigned, as in previous releases. The additional `SnapStudio_1.3.0.0_x64.msix` is an unsigned, framework-dependent evaluation package; use the portable ZIP for normal use.
- OCR, scrolling capture, and screen recording remain experimental and disabled by default.
- Automated and native x64 checks cover the local command connection, malformed input, cancellation, clipboard colors, capture and clipboard handoff, busy-dialog rejection, companion activation, and offline Help. Native ARM64, signed-package installation, and broader monitor configurations remain outside this release's validation boundary. See the attached `release-validation.txt` for exact package checks and remaining preview limits.

`SHA256SUMS.txt` verifies the attached packages and validation reports. See [all changes since 1.2.0](https://github.com/MaxAkbar/SnapStudio/compare/v1.2.0...v1.3.0).
