Get started

SnapStudio keeps captures and editable documents on your PC. Start with a screen capture, an existing image, or a transparent canvas.

  1. Finish the first-run setup. Review the capture hotkey, cursor option, clipboard preference, and storage location.
  2. Choose New capture → Region, or press Ctrl+R, and select an area of your screen. Use Esc to cancel the capture.
  3. Choose Arrow or Text beside the canvas and draw on the image. Change the selected tool or object's appearance in Properties.
  4. Choose Copy to place the edited image on the clipboard, or Export → PNG to save a shareable file.

For an existing file, use Open (Ctrl+O). To start from scratch, use New (Ctrl+N) and enter the canvas width and height. The checkerboard represents transparency; PNG export preserves it.

Your workspace keeps editable documents. Export creates a separate copy for sharing; it does not replace the editable document.

Capture your screen

Open New capture and choose the target that fits your task.

Capture modes

Full Screen (all displays)Capturing the complete desktop in one image, preserving the positions of your monitors.

SnapStudio minimizes before the region preview or screen capture, keeping its window out of your screenshot. For window and display captures, choose your target first; the picker remains visible until you confirm. The workspace returns after capture, cancellation, or an error, preserving its normal or maximized layout. If it was already minimized, it stays minimized.

Include the mouse pointer

Enable Include cursor in Capture options or Settings. Still captures add the visible pointer as an editable image object in a Mouse pointer layer. Move, resize, hide, or delete it independently. Visible pointer objects appear in Copy and export.

Optional capture features

OCR, scrolling capture, and screen recording are experimental features, disabled by default. Their controls appear only when the matching feature is enabled in Settings; save and restart to apply feature changes.

  • OCR: extracts text locally when enabled. Recognition depends on the image and the Windows OCR languages available.
  • Scrolling capture: attempts to capture a detected scrollable target. Some apps do not support this; a partial result may be kept when scrolling cannot finish.
  • Screen recording: records a selected window or display to a local MP4 file. Audio can be off, microphone, or system audio. Simultaneous microphone and system audio, and webcam capture, are not implemented.

Find your way around

  • Library, on the left: choose a folder, search, and browse captures in pages of ten.
  • Canvas, in the center: view the current image and edit its objects. The tool rail sits beside it.
  • Inspector, on the right: switch between the Properties, Image details, Capture options, and Guides tabs. Each tab scrolls independently, and Layers stays available below. Selecting a drawing tool opens its Properties; perspective tools open Guides. With a tab focused, use the arrow keys to move between tabs and Enter or Space to select one.
  • Image title menu (…): rename, duplicate, move, or remove the current capture.

Drag the divider beside either side pane to resize it. Unpin a pane to collapse it to a narrow rail, then pin it to restore its width. Folders and search, Captures, and Layers can also collapse independently.

Choose Focus mode, or press F8, to hide both side panes. Choose it again to restore their previous widths and open states.

Hold Ctrl and turn the mouse wheel over the editor to zoom around the pointer. Use Ctrl+1 to fit the canvas and Ctrl+0 for actual size. Normal scrolling moves around the canvas.

Select, move, and crop

Selection tools (M): choose image pixels

Click the selection tool in the toolbar, or use Selection tool in Properties, to choose a shape. Selections work over the visible image without selecting or moving annotation objects.

  • Rectangular / Elliptical marquee: drag a rectangle or oval. Hold Shift when starting a new selection for a square or circle. Drag inside an existing marquee to move its boundary.
  • Lasso: drag a freehand outline. Releasing the pointer closes the outline.
  • Magic wand (W): click a color to select similar pixels from all visible layers. Tolerance runs from 0 (exact match) to 255. Contiguous limits the selection to connected pixels; turn it off to include separate matching areas.
  • Polygonal lasso: click successive corners to build a selection with straight edges. Click the first corner, double-click, or press Enter to close the outline. Backspace removes the last corner; Esc cancels the outline and restores the previous selection.
  • Choose New, Add, Subtract, or Intersect in Selection mode. With a selection present, Shift adds; Alt subtracts; Shift+Alt intersects. Holes and separate selected regions are preserved.
  • Arrow keys move the selection boundary by one image pixel; Shift moves it by ten. Image pixels and objects stay in place.
  • Ctrl+A selects the full canvas, including empty areas.

Copy selection (Ctrl+C) copies the selected pixels with transparency outside the shape. Paste can place the result in a new layer or a new image. Fill selection (Shift+F5) lets you choose a color and adds one editable fill object to the active layer, with undo and redo. Right-click a selection for these actions, Invert (Ctrl+Shift+I), Select all, or Deselect.

Mask or crop one layer

Select a layer, make a pixel selection, then right-click inside it or open Properties. Add layer mask reveals only the selected shape on that layer, including holes and separate areas. Adding a mask again replaces its previous shape. This isolates existing objects and future edits on that layer while retaining the original artwork.

Crop layer to selection limits that layer to the selection's bounding rectangle. Canvas dimensions and other layers stay unchanged. Layer masks and crops affect annotation objects and pasted image layers; the original capture remains a separate background. Paste an image as a layer to mask or crop it independently.

Layers show Mask or Cropped beside their object count. Right-click a layer to disable, enable, or remove its mask, or choose Reset layer crop. Each change supports undo and redo and survives saving and reopening. Copying and exporting use the same visible result.

In New selection mode, drag inside the selected pixels to move only the outline with any selection tool. Image pixels, objects, and existing layer masks stay in place. Changing the active layer keeps the pixel selection. Add, Subtract, and Intersect modes continue editing its shape.

Move (V): work with objects

With a drawing tool active, hover over an existing object to see its outline and move cursor. Click or drag to select and move it; its handles resize it without changing your active drawing tool. Hold Ctrl to draw or place an overlapping object instead. This works with shapes, text, pen strokes, fills, images, stamps, and perspective objects in both editors. On the main canvas, the Fill tool still fills on click, and M still selects pixels.

In Move (V), click an object to select it, then drag to move it. Shift-click or Ctrl-click adds or removes individual objects. Drag an empty area to select overlapping objects. Ctrl+A selects every visible object. Shift-drag constrains movement to one axis.

Resize handles appear for a single selected object. Arrow keys move the selection by one image pixel; add Shift for ten pixels. Clicking an object in Layers switches to Move. Switching between Marquee and Move keeps the selected area and objects.

Snap objects into alignment

Snap, beside the zoom controls, starts enabled. While moving an object, its left edge, horizontal center, or right edge can align with other objects; its top, vertical center, or bottom can align too. Canvas edges and centers are also available. Magenta guides show the matching alignment while you drag and disappear when the drag ends.

Multi-selected objects snap using their combined bounds and keep their spacing. Hidden objects, hidden layers, and the objects being moved are excluded as targets. Resize handles also snap on shapes, images, SVG objects, and line endpoints. Text objects snap when moved; text resizing continues to follow its font layout.

Hold Alt while dragging to bypass snapping temporarily, or turn Snap off. Shift keeps movement on one axis and preserves square/circle resizing. Snapping feels the same at different zoom levels. Arrow keys keep their exact one-pixel steps. Each completed drag remains one undo step; Esc cancels the drag.

Use a resizable grid

Choose Grid beside Snap to show or hide the canvas grid. Use its arrow to open Grid settings and change Cell spacing from 4 to 512 image pixels. The grid starts at the image's top-left corner; stronger lines mark every fourth visible cell.

With the grid visible, Snap to grid aligns moving objects, groups, and resize handles to its lines. The main Snap switch must also be on. Turn off Snap to grid to keep object alignment while using the grid only as a visual guide; hiding the grid stops grid snapping too. Hold Alt to bypass all snapping.

At low zoom, fine grids use wider spacing so the lines stay readable. The settings show the visible spacing, and snapping uses those same lines. Zoom in for a finer grid. Grid settings apply to the current workspace session. The grid is an editing overlay and never appears in copied or exported images.

Perspective in the Grid menu

Guide families: select a compact family row to show its editor. The eye button hides that family and restores its previous opacity when shown again. The base grid and every VP have independent color, opacity, and density controls. One-point has Base grid + VP 1; two-point adds separate Left and Right VPs; three-point adds Third VP. Four-point has Base grid, Left, Right, Top, and Bottom VPs. Five-point also has a Center VP. Curved guides split at the center so each VP's half has its own settings. Density changes only that family's guide count and object snap targets. Zero opacity hides that family's guides and removes those guides from object snapping; drawing tools still follow the mode's perspective directions. Rectangular mode uses cell spacing for its base grid. Settings are shared by both editors for the workspace session and stay out of saved artwork and exports. Reset guide families restores the family defaults; Reset perspective positions keeps family settings while resetting positions.

To follow a whole curve, choose Perspective line in the Line tool drawer or use its separate icon in the SVG designer. Your click fixes the start, including between visible guides. The initial drag chooses a guide direction and locks it for the stroke. One-, two-, and three-point modes follow straight perspective directions; four-point mode also follows the full vertical curves; five-point mode follows horizontal or vertical curves, or a straight depth line through the center. Curved strokes stop at the canvas or curved-grid rim.

Selecting Perspective line shows the grid and chooses four-point mode if the grid was rectangular. Existing perspective settings and the snap preference are retained. Keep Grid and Snap to grid on, plus the canvas's main Snap switch. Hold Alt, turn snapping off, or hide the grid to draw a free straight line. Each stroke is one editable open SVG path with no fill, its stroke color, width, dash style, opacity, and one undo step. Use Edit SVG to edit it. The ordinary Line and Arrow tools stay straight, using a curve's local direction when snapping.

To draw a whole face, open the Rectangle tool drawer, choose the Front, Side, or Ground plane, then Perspective rectangle. It is a separate tool; drag opposite corners to make its edges follow the active perspective, including curves in four- and five-point grids. The SVG designer has the same tool beside Rectangle, with a Perspective plane selector. Front is width × height, Side is depth × height, and Ground is width × depth. A one-point Front face stays parallel to the image.

The clicked corner stays fixed, and faces stop at canvas edges, vanishing axes, and the curved-grid rim. Start curved faces inside the rim. Selecting the tool shows the grid and chooses two-point mode if the grid was rectangular. With snapping off or Alt held, it draws a flat face. Each face is one SVG object with one undo step; use Edit SVG to edit its paths and colors. The regular Rectangle tool keeps its normal behavior.

Move perspective objects: with perspective snapping on, dragging, arrow-key nudges, and SVG X/Y position changes recalculate a Perspective line or Perspective rectangle against the active grid. Lines retain their guide family; rectangles retain their plane. Their appearance stays the same and each move is one undo step. Hold Alt, turn snapping off, or hide the grid for a free move. Moving with perspective snapping on again fits the object to the grid at its new position. Changing the grid leaves existing objects in place until their next snapped move.

Resizing and rotating still transform the saved artwork. Editing path geometry can detach its perspective behavior to preserve your custom edits on later moves; changing colors, stroke width, dashes, or opacity retains it. Ordinary shapes and custom SVG artwork keep their normal movement behavior.

In the Guides inspector, choose the icon for Rectangular, 1-point, 2-point, 3-point, 4-point curved, or 5-point fisheye. The Grid button shows the current mode's icon. Choosing a different mode turns the guides on. Rectangular mode keeps its cell-spacing control; perspective modes have a separate density for each guide family.

The Guides tab beside Properties keeps perspective controls beside the canvas. Its compact family list expands one editor at a time. Perspective line and Perspective rectangle are grouped here with the rectangle plane selector. Selecting a perspective tool opens Guides with point editing off; its contextual toolbar provides stroke color, width, and the rectangle plane. Open Guides manually or check Edit points on canvas to edit the guides.

Drag a VP handle or the horizon on the canvas. Off-canvas VPs appear at the image edges while retaining their actual positions, so a drag changes the position without jumping to the edge. Type exact coordinates for points outside the artwork. Focus a handle and use arrow keys for one image pixel (one SVG unit in the designer), or Shift for ten. Escape cancels an active drag. Curved poles share the curve radius, so moving one also adjusts its linked poles. Guide edits leave artwork and document undo history untouched.

Change Horizon Y and the displayed vanishing-point positions to compose the view. Each value has an editable number box and a slider; dragging a slider previews the guides immediately. Right-click the canvas and choose Grid and perspective… to open the same controls, including while objects or pixels are selected. Positions are percentages of the image or SVG viewBox, so negative values and values above 100 place vanishing points outside the artwork. Three-point mode adds a third point above or below the horizon. Four-point curved combines two horizontal vanishing points with vertical curves converging above and below; five-point fisheye uses two curved guide families and depth lines through the center. Curve radius uses a percentage of the shorter image side. Reset perspective positions restores the selected mode's defaults.

Perspective modes, positions, and density are shared between the canvas and SVG designer for the current workspace session. With Grid and Snap to grid on, objects and resize handles follow the visible straight or curved guides. The canvas also requires its main Snap switch. Hold Alt to bypass snapping. Snapping positions or resizes objects without warping their artwork; the guides remain outside saved artwork, clipboard images, and exports.

With perspective snapping on, lines and arrows follow a perspective direction anywhere, even between the visible guides. Your click fixes the start point; your initial drag chooses the closest perspective direction and locks it for that stroke. Guide density only changes the reference lines. In four- and five-point modes, straight tools use a curve's local tangent or a vanishing-point direction. This works on both the canvas and in the SVG designer. Perspective directions take priority over the SVG editor's Shift 15° angles. Turn off Snap or Snap to grid, or hold Alt, to draw freely.

Other canvas drawing tools snap shape corners and SVG tool objects to nearby guides, and the saved object matches the preview. Shift preserves squares and circles. Text uses its final measured size for placement; stamps and objects added with the toolbar snap using their actual bounds. Hold Alt during drawing or stamp placement to bypass snapping. Pen strokes, fill operations, and pixel selections retain their normal freehand or pixel behavior.

Crop and resize

Make a selection around the part to keep, then choose Crop or press C. Crop keeps the selection's bounding rectangle, including padding, and retains objects inside that rectangle. Copy preserves a nonrectangular selection's shape. Undo restores the previous image. Resize changes the image dimensions; choose pixels or percentages and use the aspect-ratio lock to keep proportions.

Ctrl+D deselects. Esc cancels an active drag and restores its previous selection, or clears the selection when idle.

Draw and annotate

Choose a tool, then draw on the canvas. Use Properties to set color, stroke width, opacity, or other options. Select an existing object with Move to edit its appearance.

Text boxes fit their content. Resizing a text object scales the text. Type a stroke width or text size into the textbox when you need a value beyond the slider range.

The fill bucket preserves a shape's outline. On an image area, adjust tolerance to include similar colors. Fill changes support undo and redo.

Right-click the image background with no object selected to switch tools. Right-click an object to duplicate, hide/show, arrange, move to a visible layer, or delete it. Mixed object selections show only shared Properties.

Blur remains editable in your workspace. Before sharing, export or copy the result and check that sensitive details are sufficiently obscured.

Work with layers

Layers keep groups of objects together. Select a layer to work in it, and use the add button to create another. Expand a layer to select its objects.

  • Right-click a layer to rename it, move it up or down, choose a color label, or delete it. These actions apply to the layer you clicked. Custom color opens a picker with a hex entry.
  • Right-click an object to change its order within the layer or move it to another visible layer.
  • Hide objects when you want to leave them out of the rendered image without deleting them.
  • Use the delete-layer action to remove a selected layer. SnapStudio asks for confirmation if it contains objects; the last remaining layer cannot be deleted.

Layer changes, object edits, and deleting a layer can be undone with Ctrl+Z and redone with Ctrl+Y. Duplicating or deleting several selected objects is one undo step.

Reuse designs and SVG artwork

Saved tool designs

Choose Design at the bottom of the tool rail, or press D, to manage reusable styles. Right-click a drawing tool to create a design. Tools with designs show an arrow that opens their design drawer; a tool shortcut activates its last chosen design.

Depending on the tool, designs save color, fill, stroke width, text size, opacity, corners, and font. Rectangle, ellipse, line, arrow, and pen support dashed and dotted designs. Existing objects keep their own editable styles. Import and export JSON design packs to reuse saved designs.

SVG designs

In source builds, choose Custom SVG under Line style, then Choose / design SVG pattern…. New SVG pattern… opens the SVG editor to draw and save one repeat. Apply it to rectangles, ellipses, lines, arrows, or pen strokes; repeats follow the stroke and rotate with curves, retaining the SVG colors. Line width controls motif size, while Scale and Spacing adjust the repeats. The SVG designer's Custom SVG line style uses the same saved patterns. Editing a library pattern leaves existing objects' embedded motifs unchanged. Choose a standard line style to remove the pattern.

Choose Design → New SVG tool for a transparent canvas, Design SVG in a tool drawer to start from its artwork, or Import SVG for a local file. Save into Custom shapes (K) or an existing tool drawer. Right-click a preview to edit it or copy a built-in design.

Place a design on the canvas as one SVG object. Select it and choose Edit SVG in Properties or the context menu to change its internal shapes, paths, fills, strokes, and text. Changes affect that object; its reusable tool and duplicates keep their artwork. The designer supports grouping, transforms, undo/redo, and direct SVG source editing. Hold Shift to snap line, arrow, move, or rotation angles in 15-degree increments.

In source builds, use the designer's Edit menu or right-click artwork or an Objects row for duplicate, delete, cut/copy/paste, group/ungroup, stacking order, rotate, flip, path editing, Properties, and Guides. Duplicate and Delete also appear above the Objects list. Right-clicking a selected object keeps your multiple selection. Shift+F10 opens the menu from the canvas or a focused Objects row; arrow keys navigate and Escape closes it. Copy/paste works between objects in the current SVG editor session and preserves embedded resources and custom line patterns. Text fields and SVG source retain normal text editing. Use Ctrl+D to duplicate, Delete to remove selected objects or the active path node, Ctrl+G to group, and Ctrl+Shift+G to ungroup. Ctrl+[ / Ctrl+] moves objects backward/forward; add Shift for back/front. Object edits support Undo/Redo.

In the SVG designer, Snap beside Grid aligns object edges and centers while moving or resizing. Canvas edges and centers are included, and groups or multiple selections use their combined bounds. Magenta guides show the match. Hold Alt to bypass snapping or turn Snap off for free object positioning. This preference lasts while the designer is open; guides and settings stay outside saved artwork and undo history.

In source builds, Perspective targets in Properties lets each object use only chosen VP guide families. Select an object, choose None, then enable the VPs you need; All guides restores automatic choice. With nothing selected, the control sets the default for new drawings in this session. Existing objects keep their choices. Guide visibility and object alignment stay available. Multiple selections show mixed checkboxes, and a combined move uses only shared targets. Choices support Undo/Redo and survive duplication, save, and reopen. The main canvas has the same setting in Properties.

Perspective lines follow their allowed directions; changing their targets takes effect on the next move. Opposing curved poles share a curve direction: Top/Bottom permit vertical curves, and Left/Right permit horizontal curves in five-point mode. Snapping to visible colored halves still filters each half independently. Perspective rectangles keep the axes of their selected plane. None disables perspective constraints; Alt and the master Snap switch still bypass them.

Choose Grid to show or hide an editing grid. Open Grid settings to change cell spacing from 4 to 512 SVG coordinate units and toggle Snap to grid. These grid preferences are shared with the main canvas for the current workspace session. Fine grids use wider visible spacing at low scale, and snapping follows those visible lines. With Snap on, Snap to grid adds alignment to visible grid guides; the closest alignment wins. Turning Snap off also disables grid and perspective snapping. Perspective-bound artwork continues to follow its guide family while perspective snapping is active. Hold Alt to bypass snapping. Object movement, resize corners, shape endpoints, and path anchors can snap to the grid; freehand strokes and Bézier control handles remain free. The grid is a guide only; it is not included in saved or exported SVG artwork.

Imports accept static vector shapes, paths, text, groups, transforms, gradients, and internal references. Scripts, external resources, raster images, filters, animation, and foreign HTML are rejected. SVGs are limited to one million characters, 4,096 elements, and 32 nesting levels. Font appearance depends on the installed fonts.

Place stamps

  1. Choose Stamps on the tool rail or press S. Search by name or filter the gallery by category.
  2. Choose a stamp. In Properties, set Stamp size to its longest edge in image pixels (16–1,024). Its proportions are preserved, and oversized stamps fit the image.
  3. Click the image to place a copy in the active visible layer. Keep clicking for more copies. Each placement is one undo step.
  4. Hover a placed stamp and click or drag to select, move, or resize it, or use V. Hold Ctrl to place overlapping stamps. Select it and choose Edit SVG to change its artwork, or adjust opacity in Properties.

Build your own gallery

The gallery includes 16 symbols and status labels. Choose Import SVG to save a local SVG as a custom stamp. Select an existing SVG object and choose Save as stamp in Properties or its right-click menu to reuse your own artwork.

Right-click a custom gallery item to rename it, change its category, or remove it. For an icon added through online search, choose Source and license… to review its saved author, license, and source. Built-in stamps stay available. Library changes do not change copies already placed in an image; each copy stores its own artwork and any source and license metadata. Custom stamps are saved locally in stamps.json under the app's data folder.

Search online with Iconify

  1. Choose Search online… in Stamps. Enter a keyword and choose All collections, Heroicons, Tabler, or Lucide.
  2. Click Search or press Enter in the keyword field. Browse the preview pages, then select an icon to review its author, license, and source.
  3. Choose Add to stamps to save a local SVG copy and select it. Click the image to place it. Saved copies work offline.

Online search is optional and needs no account or API key. Opening the dialog, typing, or changing the collection makes no automatic network requests. After you submit with Search or Enter, search words and requested icon IDs go to api.iconify.design, along with ordinary connection information such as your IP address. Screenshots and documents are never uploaded. The SVG and its source and license metadata are saved locally with the stamp and each placed SVG object.

Find free SVG artwork

In your browser, try heroicons.com (MIT), tabler.io/icons (MIT), or lucide.dev/icons (ISC and some MIT artwork). svgrepo.com offers many icons with different licenses; check each icon's terms. Keep the applicable license notices when redistributing artwork. Download an individual SVG, then import it into SnapStudio.

Stamps use the same static SVG support and import limits described in Reuse designs and SVG artwork. Fonts depend on what is installed on your PC.

Organize your library

Choose All captures, Unfiled, or a folder from the Library dropdown. Search works across every page in the selected view and source filter. Use the arrows below Captures to browse pages of ten. New captures return to page one.

Folders and imports

The + beside the dropdown maps a local folder. SnapStudio imports editable copies of PNG, JPEG, and BMP files and can include subfolders. Refresh adds newly discovered files from the selected mapping, or checks all mappings when All captures or Unfiled is selected. Previously copied files are not added again; edits and copies stay intact if an original changes or disappears.

Use the … beside Captures to create a group, perform a one-time import, rename, or remove a group. Right-click a folder in the open dropdown to rename or remove it. Removing a folder stops its mapping; removing a folder or group keeps its captures and returns them to Unfiled.

Capture actions

Right-click a capture to rename, duplicate, move to a folder, show its stored image in File Explorer, remove it from recent captures, or delete its image to the Recycle Bin. Actions apply to the capture you clicked. Duplicates keep editable layers, tags, and group membership and can be edited independently.

Remove from recent captures keeps the image file. Delete image (Recycle Bin) asks for confirmation and recycles the source image when no other document references it. For imported images, Show in folder reveals SnapStudio's editable copy.

Tags

Choose Edit tags… from a capture's context menu, its title menu, or Image details. Enter labels separated by commas or new lines. Search the tag library under Find or add a tag, or type a new label and choose Add. Each label can contain up to 64 characters; there is no tag-count limit.

Remove a label from the field and save to untag that capture. Library search includes tags; #Design matches that exact tag, ignoring case, within the selected folder and source filter. Tags stay with the editable document and leave the source image file untouched.

Copy, paste, and export

Copy the result

Choose Copy or press Ctrl+C. With a pixel selection, Copy includes the selected parts of the visible image and its objects, preserving transparency outside the selected shape. With object selections, Copy uses their bounding rectangle. With no selection it copies the whole edited image. Use Ctrl+D first if you want the complete image.

Paste an image

Paste (Ctrl+V) offers New layer to place a clipboard image over the open image, or New image to open it as a separate document. Pasted layers retain transparency and can be moved or resized independently. The arrow beside Paste offers both actions directly. Ctrl+Shift+V always creates a new image. With no image open, Ctrl+V creates a new document.

Export a file

Choose Export → PNG, JPEG, or PDF and select a destination. Export renders the edited document with its visible objects. PNG preserves transparency. Keep the local editable document if you want to change objects later; exported images do not retain editable layers.

Settings and local data

Open Settings in the Library pane. Review the capture hotkey, Include cursor, clipboard preference, document storage, and feature switches, then save.

Appearance

Under Appearance → Theme, choose Dark, Light, or Use system setting. Save to apply the theme immediately. Help follows the app's theme.

Storage

The default document location is %LOCALAPPDATA%\SnapStudio\Documents. Choose another location in Settings if needed. The File system backend keeps document metadata in JSON sidecars; Database keeps it in the local snapstudio-documents.db file. Source images, thumbnails, OCR cache files, and recordings remain local files.

Settings are kept in %LOCALAPPDATA%\SnapStudio\settings.json. Import and export settings through JSON files. Storage location, storage backend, and feature-switch changes require restarting SnapStudio; save your work before restarting.

Privacy and diagnostics

SnapStudio has no cloud account, sync, telemetry upload, or remote capture processing. Captures, recordings, settings, and logs stay local. Copying, exporting, or opening a file in another application puts that copy under the destination's control.

Local diagnostic and recovery logs are in %LOCALAPPDATA%\SnapStudio\Logs. Help loads its bundled HTML on your PC and keeps its WebView2 cache in %LOCALAPPDATA%\SnapStudio\HelpBrowser. It does not need an internet connection.

Troubleshooting

A feature or shortcut seems unavailable

OCR, scrolling capture, and recording are hidden when their feature switch is off. Save feature changes and restart. Editor shortcuts do not run while a text field or dialog has focus; click the canvas and try again. Some actions also need an open image or a selected object.

Copy contains only part of the image

Check for a marquee selection. Press Ctrl+D to clear it, then copy again for the whole edited image.

An imported image does not update

Mapped folders keep editable copies. Refresh discovers new files; it does not overwrite an existing copy when the original changes. Use a one-time import or Open to work from the changed original.

Help cannot load

Use Retry loading help in the toolbar. If files are missing, extract the entire portable ZIP or reinstall the complete package so the Assets/Help folder is present. The viewer requires the Microsoft Edge WebView2 Runtime, as does the SVG designer. If the runtime is missing, install it through Microsoft's official WebView2 distribution, then reopen SnapStudio. If the viewer stops, close the Help window and open it again.

You need to report a problem

Record the steps, expected result, actual result, and app version. Include a sample image only when you are comfortable sharing it. Local logs can help diagnose a failure; review them before sharing. Experimental features still need broader hardware and packaged-build validation.
